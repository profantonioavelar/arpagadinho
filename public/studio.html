☁️ Armazenamento em Nuvem Permanente (Render)

O Render utiliza um disco virtual temporário: quando o servidor dorme por inatividade ou reinicia, os arquivos locais do disco são reinicializados. Para que os vídeos e fotos dos estudantes nunca sumam, a plataforma integra-se à sua conta do Cloudinary.

Como Ativar no Painel do Render (Passo a Passo):

  1. Acesse seu painel no Render Dashboard e abra o serviço arpagadinho.
  2. No menu lateral esquerdo, clique em Environment.
  3. Adicione ou verifique se estas 3 variáveis estão configuradas:
CLOUDINARY_CLOUD_NAME = dvb6nwylo
CLOUDINARY_API_KEY = 224845422173297
CLOUDINARY_API_SECRET = Fr90MmOsFmGDELYPsbR6bbd10eo

⚠️ Atenção: digite "CLOUDINARY" completo (com "CLO" no início).

4. Clique no botão "Save, rebuild, and deploy". O Render reiniciará com armazenamento permanente ativado!

🛡️ Backup de Segurança:

Você pode clicar no botão "📥 Fazer Backup (JSON)" no topo do estúdio a qualquer momento para baixar um arquivo com todos os dados e links das artes para o seu computador.
