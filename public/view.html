Acesso à Câmera Bloqueado

O navegador não conseguiu acessar a câmera do dispositivo.

Como resolver:
  • Navegadores móveis exigem HTTPS para abrir a câmera via Wi-Fi. Inicie o servidor com: npm run dev:https
  • Conceda a permissão de câmera nas configurações do navegador do seu smartphone.
  • Se estiver testando pelo computador, verifique se a webcam está conectada e liberada.
